Privacy Policy: YouTube Automation Uploader

Last updated: 21 November 2026

Who uses this app

YouTube Automation Uploader is an internal tool used only by its owner to manage the owner's own YouTube channels. It isn't offered to the public, and it doesn't ask anyone else to sign in.

What data it accesses

When the owner signs in with Google, the app asks for permission to upload videos and manage the owner's own YouTube channels (the youtube.upload and youtube scopes). It uses this only to upload the owner's videos, set thumbnails, schedule publishing and add videos to the owner's playlists. It also reads the channel ID to check that each upload goes to the right channel.

What data it stores

The Google sign-in token is kept only on the owner's own computer, in a file that only the owner can read. The app keeps a local log of the videos it uploaded (title, video ID, link, date). It doesn't collect, sell, share or send any data to third parties. It doesn't use Google user data for advertising.

YouTube and Google

This app uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time at Google account permissions.

Deleting data

Revoking access in Google account permissions and deleting the local token file removes everything the app holds.

Contact

For questions, open an issue on this site's GitHub repository.
